# Phase 12 ML 3단계 (US 비율·동종업 상대 비율·피처 탐색 UI·하이퍼파라미터 탐색·백엔드) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Phase 7 에서 이연한 네 항목(US 연도별 재무비율, 동종업 중앙값 대비 비율, 피처 행 탐색 UI, 하이퍼파라미터 탐색)과 선택 백엔드(LightGBM·PPO)를 구현해, US 모델이 비율 피처를 갖고 KR·US 모두 동종업 상대 피처로 학습되며 운영자가 피처 행을 웹에서 보고 파라미터를 근거 있게 고를 수 있게 한다.

**Architecture:** 비율은 기존 `basic_ratios` 공통 키를 그대로 쓰고, US 는 EDGAR companyfacts 1회 조회로 연도별 값을 만든다(사업연도 Y 값은 Y+1 년 4월 1일 "그때까지 제출된 10-K" 로 — KR 과 같은 룩어헤드 규칙). 동종업 상대 비율은 사람이 관리하는 `config/sectors.yaml`(종목→11개 대분류) 위에서 `write_rows` 가 날짜 파일 전체를 다시 계산해 넣는 파생 열이라 백필 묶음 쓰기와 멱등성이 유지된다. 하이퍼파라미터 탐색은 기존 워크포워드 폴드의 **마지막 폴드를 홀드아웃**으로 떼고 나머지(dev)에서만 고른다. 웹은 읽기 전용 조회 API 2개 + Data 페이지. 백엔드는 `ml.yaml` 값만 바뀌고(`auto`) 코드 기본값은 `sklearn`/`cem` 그대로다.

**Tech Stack:** pandas, scikit-learn, lightgbm(선택), stable-baselines3 2.3 + torch 2.2.2(darwin x86_64 핀), FastAPI, React/TypeScript.

**Spec:** `docs/superpowers/specs/2026-10-09-trading-agent-design.md` §3(수집 표 201행 "동종업 중앙값 대비", EDGAR 동일 비율), §9.1(퀀트 모델·워크포워드·승격), §8(웹 UI 읽기 전용 조회 토큰 없음). 이연 출처: `docs/TODO.md` Phase 7 절 "Phase 7 이연 유지" 항목과 LightGBM·PPO 사용자 확인 항목(2026-10-20 사용자 결정: 전부 진행).

## Global Constraints
- 기본값 불변: `QuantModelCfg.backend` 코드 기본 `sklearn`, `RlSizerCfg.backend` 기본 `auto`(기존). 설정 파일(`config/ml.yaml`)만 `auto` 로 바꾸고 `templates/config/*.yaml` 패리티 유지(새 `sectors.yaml` 포함).
- 룩어헤드 금지: US 연도 Y 비율은 `date(Y+1, 4, 1)` 시점에 제출된 10-K 만. 동종업 중앙값은 **같은 날짜** 행끼리만.
- 피처 스토어 스키마 열 추가는 `FEATURE_COLUMNS`·`FEATURE_DTYPES` 에만 추가하고 옛 파일은 NaN(기존 reindex 경로). 파생 열 이름 접미사 `_vs_sector`.
- 하이퍼파라미터 선택은 홀드아웃(마지막 폴드)을 보지 않는다. 자동 적용 없음(JSON 리포트 + `state/models/quant_tune/<ts>.json`).
- 조회 API 는 토큰 없음, 입력 검증(시장 KR|US → 400, ticker 정규식, `days` Query 범위 → 422).
- `uv run pytest`·`uv run ruff check src tests` 0건, `cd web && npm run typecheck && npm test && npm run build`.
- 셸 스크립트 금지, 경로는 pathlib, 금액 Decimal, 한국어 메시지.

## Review Focus
- 섹터 구성원이 3개 미만인 날(백필 초기·US 소수 섹터)의 `_vs_sector` 는 0 이 아니라 NaN 이어야 한다 (Task 2 테스트).
- 10-K 를 4월 1일 뒤에 제출하는 회사(지연 제출)의 연도 Y 값이 Y+1 년 4월 1일 행에 들어가면 룩어헤드다 — `filed > asof` 제외 (Task 1 테스트).
- `write_rows` 의 파생 열 재계산이 다른 시장·다른 종목 행을 지우거나 두 번 써도 값이 바뀌지 않아야 한다(멱등) (Task 2 테스트).
- `ml tune` 이 홀드아웃 폴드 지표로 후보를 고르면 과최적화다 — dev 폴드만으로 선택되는지 (Task 3 테스트).
- `/api/features/history` 의 `ticker` 에 경로 문자(`../`)가 오면 400, `days` 범위 밖은 422 (Task 4 테스트).
