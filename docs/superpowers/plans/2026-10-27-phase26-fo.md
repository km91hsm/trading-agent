# Phase 26 — 선물옵션 방향성 레인 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 국내 지수 파생(코스피200 선물 롱/숏, 옵션 콜·풋 매수·매도)을 현물과 같은 모양(수집 → 세션 → 파이썬 게이트 → 주문 → 장중 모니터·재평가 → 기록)으로 모의 선물옵션 계좌에서 돌리는 별도 레인 `fo/` 를 만든다. 배수는 LLM 이 한도 안에서 정하고, 방향은 현물 국면·전략가와 대조한다.

**Architecture:** 계좌 `asset: fo` 로 분리된 레인. 공유는 브로커 조립·원장 `orders/fills`·알림·세션 러너·빠른 대기열·웹 틀뿐이고, 포지션 상태기계·실행 키(`fo_order_legs` 행)·게이트·사이징·모니터·재평가는 `src/trader/fo/` 전용이다. 5단계 브랜치 체인(`main` → `feat/phase26-1-fo-broker` → `-2-store-gate-exec` → `-3-session` → `-4-daemon-web` → `-5-docs-review`), PR 은 직전 브랜치 대상, 단계마다 Codex + Claude 교차 리뷰.

**Tech Stack:** Python 3.12·uv·typer·pydantic(extra=forbid)·SQLite(WAL)·httpx/respx / React+Vite+Vitest / claude CLI(`-p`) / KIS Open API 국내선물옵션(모의 주간 TR).

**Spec:** `docs/superpowers/specs/2026-10-27-fo-lane-design.md`(사용자 승인 2026-10-27, Codex 플랜 리뷰 4회 반영). 설계 §0~§8·범위 조정·미확인은 스펙이 정본이며 이 플랜은 그 결정을 작업으로 옮긴다.
